This is a database for data on how different materials and orientations reflect light.

1) The data you should use is located in the FaSTMM2_data folder. The name is a bit of a lie since it contains data from FaSTMM runs and FaSTMM2 runs, although it should not make a difference since FaSTMM2 just improves speed.
2) Do not us MSTMM data, its just bad. Any file ending in .dat is from an MSTMM run and should not be used.
3) To query data, download the index.html file and use the search bar. I didn't make it and it has lots of repairs needed, so I will be working on that.
4) Each file's name is formatted as follows: {name}_{number of particles}_{size}size_{orientations}ave.h5. If the size is 0.15, then {size} will be 015, if 0.1 then 01, etc.
5) To see details on how the h5 file is formatted, see https://bitbucket.org/planetarysystemresearch/fastmm2/src/main/
6) Database is still going through changes, some FaSTMM runs are not named correctly currently.
7) If you have any other questions, email me at jmckenn005@gmail.com
